# Банковский виджет
___
### Данный виджет предназначен для оптимизации пользовательского интерфейса приложения и обеспечения предоставления всей релевантной информации в доступной форме. 
#### _Проект находится на стадии разработки и протестирован неполностью, возможны ошибки и баги._
___
## Описание
### Виджет отображает информацию о банковском счёте, включая текущий баланс и номер счёта. Для обеспечения конфиденциальности, номер счёта подвергается маскировке. Дата, представленная в формате `YYYY-MM-DDThh:mm:ss.sss`, конвертируется в стандартный формат `DD.MM.YYYY`.
## Зависимости
### Установка зависимостей будет в этапе `Установка`
* Python (не меньше 3 версии)
* Git
* pip
___
## Установка
### Установка Python
* По ссылке скачиваем и устанавливаем [Python](https://www.python.org/ftp/python/3.14.2/python-3.14.2-amd64.exe)
### Установка pip
Пакет `pip` входит в стандартную конфигурацию `Python`, в противном случае выполните команду в Poweshell `py -m ensurepip --upgrade
`
### Установка проекта из GitHub
1. На главной странице проекта ищем вкладку `Code`
2. В появившемся окне нажимаем `Download ZIP`
3. Разархивируем архив в любую папку
___
## Использование
### Для запуска и использования функций виджета нужно:
1. Открыть `Powershell` в папке с проектом (ПКМ и в меню ищем `открыть в терминале`)
2. Вводим в терминал `python main.py`
### Функционал
* Маскировка номера счета или карты
* Форматирование даты из стандарта ISO, в привычный вид
* Фильтрация списка по параметрам
* Фильтрация списка по дате
## Тестирование (Pytest)
В проекте используется фреймворк Pytest для проверки корректности работы виджета: маскировки номера счёта, конвертации даты и расчёта баланса.
### Установка зависимостей для тестирования
1. Для запуска тестов, установите Pytest. `pip install pytest`
2. Устанавливаем все зависимости `pip install -r requirements-test.txt`
### Запуск тестов
Для запуска, в корневой дериктории проекта `pytest`
### Покрытие тестов
Для просмотра покрытия тестов `pytest --cov=src --cov-report=html`
